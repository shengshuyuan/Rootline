## 2. 已实现功能

### 2.1 族谱与人物

- 空状态创建第一位成员，或导入已有族谱。
- 新增独立人物。
- 编辑姓名、性别、在世/已故、出生和去世日期、籍贯、职业、个人简介、人生主要经历。
- 查看人物基础资料、个人简介、人生主要经历、家庭关系和完整记录；长文本支持换行与移动端滚动阅读。
- 删除人物前显示影响范围并二次确认，同步移除相关关系。
- 修改族谱名称与姓氏。

### 2.2 亲缘关系

- 新增父亲、母亲、子女、配偶。
- 将已存在人物关联为父亲、母亲、子女或配偶。
- 解除亲子或配偶关系。
- 给有配偶的人物添加子女时，自动把已记录配偶加入同一家庭单元。
- 拒绝重复关系、自指关系、祖先循环、性别与父母角色不符等错误。
- MVP 阶段明确限制每人最多一位配偶。

### 2.3 画布、视图与搜索

- 自动家庭单元布局，配偶同层、父母子女分代展示。
- 完整亲缘视图与主脉视图切换。
- 设为画布中心、折叠/展开子孙、展开全部分支。
- 画布缩放、视口适配、人物选中与详情联动。
- 按姓名、曾用名、字辈/排行、籍贯、职业、个人简介和人生经历等数据搜索。
- 搜索命中会展开目标路径、设为中心并高亮目标。
- 人物节点悬浮卡展示出生、籍贯等摘要。

### 2.4 日期与农历

- 公历与农历录入。
- 支持精确日期、年月、年、约数和未知精度。
- 支持农历闰月，并按真实农历大小月校验日期。
- 校验出生/去世和配偶关系起止日期顺序。
- 农历在详情与画布中以中文传统写法显示。

### 2.5 本地存储、备份与恢复

- 主数据自动保存到 IndexedDB，并显示保存状态与时间。
- 数据结构版本号与旧版迁移链。
- 手动创建恢复点。
- 在导入、删除、版本迁移和恢复前创建保护点。
- 恢复点最多保留 20 个。
- 加载失败时允许导出原始数据。
- 根据未导出编辑次数提醒用户备份。

### 2.6 导入、导出与分享

- 导出带版本信息的 JSON 备份。
- 兼容旧版裸 JSON 数据。
- 导入前完整校验和人物/关系数量预览；非法数据不会覆盖当前族谱。
- JSON/Excel 文件选择、拖放和 JSON 文本粘贴。
- Excel 可编辑维护表双向导入导出，包含族谱、人物、亲子关系、配偶关系和填写说明；人物表含独立“个人简介”列。
- 生成整棵家谱 PNG 分享图；支持系统分享，不可用时回退为文件下载。

### 2.7 移动端与可访问性

- 桌面端三栏工作台与移动端单列布局。
- 移动端数据菜单、搜索、视图切换和人物补录。
- 弹窗初始焦点、Tab 焦点循环、Escape 关闭与关闭后焦点恢复。
- 未保存表单关闭保护。
- 画布节点支持 Enter/Space 键盘操作。

## 3. 当前明确限制

以下不是本轮回归缺陷，而是当前产品边界或未实现能力：

- 只管理一棵当前族谱，没有多族谱书架。
- 数据只保存在当前浏览器，没有账号、多设备同步、多人协作和权限。
- 恢复点与主数据位于同一浏览器；清理站点数据后只能依靠外部 JSON 备份。
- 每人最多一位配偶，关联配偶按异性候选过滤。
- 新建人物必须选择男性或女性；“性别未知”只用于兼容旧数据。
- 主界面仅直接编辑 MVP 人物字段。曾用名、出生地、详细关系类型/日期/说明虽然已存在数据模型和 Excel，但没有完整的图形界面编辑入口。
- 亲子关系从界面新建时默认为“亲生”；收养、继亲、过继等类型主要通过 Excel 维护。
- 公历/农历切换不会自动换算，切换会清空当前日期并要求重新录入。
- 画布由布局器自动定位，不支持手动拖拽保存位置。
- 没有人物照片、相册、音视频、资料来源、页码证据、OCR 录入或人物合并。
- 没有专门的打印/书册/PDF 排版；当前只能生成 PNG 分享图。
- 自动化浏览器验收使用 Chromium，尚未在真实 Safari 上完成同等回归。
- 生产环境仍是 2026-07-14 的旧构建，本地最新版本暂未发布。

## 4. 可选新增功能

### A. 建议优先讨论：提升族谱数字化的可靠性

1. **资料来源与证据**
   - 人物、日期和关系可关联“族谱名、卷次、页码、原文、截图、录入人、可信度”。
   - 这是后续 OCR、校对和多人审核的数据基础。

2. **批量录入与人物合并**
   - 在界面内提供表格式快速录入、批量校验、疑似重复提示和安全合并。
   - 比逐个弹窗更适合大量纸质族谱数字化。

3. **关系语义补全**
   - 在图形界面中编辑亲生/收养/继亲/过继、关系说明、配偶起止日期。
   - 如真实资料需要，再将单配偶限制升级为继配/前配偶/多配偶布局。

### B. 适合第二阶段：提高资料处理效率

4. **PDF/OCR 辅助录入工作台**
   - 按页展示族谱扫描件，提取候选人物和关系。
   - 人工逐条确认后才写入正式族谱，保留页码与原文证据。

5. **多族谱书架**
   - 管理多棵族谱、切换当前族谱、单独备份与归档。

6. **打印与出版**
   - 分支家谱、指定人物上下代、大尺寸 PDF、书册式排版和打印页码。

### C. 体验增强

7. **人物媒体与时间线**
   - 头像、照片、证件、音频、视频、人物生平时间线。

8. **本地文件备份与更明确的恢复向导**
   - 定期备份检查、备份新鲜度、多份本差异预览与安全恢复。

### D. 暂不建议立即做

9. **账号、云同步、多人协作与权限**
   - 会把纯本地工具变成完整网络产品，引入身份、隐私、数据冲突、安全和运维成本。
   - 建议先用真实族谱录入验证本地 MVP，再决定是否扩展。

## 5. 建议的决策方式

下一轮不建议一次选很多功能。可以从下列方向中选一个作为主线：

- **开始真实录入**：选 A1 + A2，先做证据和批量录入。
- **先解决复杂家庭结构**：选 A3，补全关系类型与多配偶。
- **先做数字化工具**：选 A1 + B4，搭建有人工审核的 PDF/OCR 流程。
- **先做家族阅读体验**：选 B6 + C7，增加出版和人物故事。

在范围确认之前，不更新生产环境，避免新旧功能反复发布。
